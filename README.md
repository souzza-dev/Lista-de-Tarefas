# 📝 Lista de Tarefas — INCODE TECH SCHOOL

Uma aplicação simples e prática de **lista de tarefas da semana**, desenvolvida com **HTML**, **CSS** e **JavaScript puro**, como parte de um desafio da **Incode Tech School**.  
O projeto tem como objetivo praticar a manipulação do DOM, criação dinâmica de elementos e o uso de eventos em JavaScript.

---

## 🚀 Funcionalidades

- ✏️ **Adicionar tarefas:** escreva uma tarefa e adicione à lista.  
- ✅ **Marcar como concluída:** use a caixa de seleção para riscar a tarefa.  
- ❌ **Remover tarefas:** delete itens da lista clicando no ícone de lixeira 🗑️.  
- ⚙️ **Editar (em construção):** botão ✏️ reservado para futuras melhorias.  
- ⚡ Interface responsiva e leve, feita com HTML, CSS e JS puro.

---

## 🖥️ Tecnologias utilizadas

| Tecnologia | Função |
|-------------|--------|
| **HTML5** | Estrutura da página |
| **CSS3** | Estilização e layout |
| **JavaScript (ES6+)** | Lógica da aplicação e manipulação do DOM |

## 💡 Como usar

### Clone o repositório:

git clone https://github.com/souzza-dev/Lista-de-Tarefas.git


Acesse a pasta do projeto:

```bash 
cd Lista-de-Tarefas
```


Abra o arquivo ```index.html``` no navegador.

Adicione suas tarefas!
Escreva o que precisa fazer na semana, marque o que já fez e delete o que não for mais necessário.
